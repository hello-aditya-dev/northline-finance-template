# MASTER PRODUCTION BUILD PROMPT

You are acting as the senior product designer, creative director, UX architect, conversion strategist, frontend engineer, Next.js engineer, accessibility engineer, technical SEO engineer, QA engineer, product documentation writer, and digital-template release engineer for this project.

You are NOT being asked to generate a generic website.

You are building a **commercial website template product that will be sold to web designers, web developers, freelancers, studios, and small agencies who build websites for paying clients.**

The first product is:

# Accounting / Fractional CFO Firm Website Template

This must be a genuinely production-ready, multi-page, client-delivery-quality website template.

It should be good enough that a freelance web designer or small agency can:

1. buy the template;
2. replace the fictional demo company with a real client's information;
3. customize branding, services, team members, case studies, images, contact details, and content;
4. configure a contact form;
5. deploy the site;
6. confidently sell the resulting website to an accounting or Fractional CFO client.

The finished template should feel like a professional vertical website system, not a generic theme.
